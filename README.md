## How I build

- **AI agents with safeguards.** My agents carry out real tasks, with guardrails, evals and human approval for anything that cannot be undone.
- **The whole product.** Product spec, backend, web and mobile apps, and distribution.
- **Reliability from firmware.** I started out writing secure bootloaders and RTOS drivers. That work taught me to plan for failure, reliability and security from day one.
